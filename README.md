# AI Prime · Скиллы публикации

Три скилла, которые превращают приложение на вашем компьютере
в работающий сайт в интернете.

Курс [AI Prime](https://pay.larkinmd7.ru) · занятие 6.

---

## Что внутри

| Скилл | Что делает |
|---|---|
| **`docker-package`** | пакует приложение вместе с окружением, чтобы работало везде одинаково |
| **`github-publish`** | создаёт репозиторий и хранит историю изменений |
| **`timeweb-deploy`** | арендует сервер, покупает домен, публикует продукт в интернете |

Идут по порядку: упаковали → сохранили → опубликовали.

---

## Установка

### 1. Скачать

```bash
git clone https://github.com/ВАШ-АККАУНТ/ai-prime-skills.git
```

Или кнопкой **Code → Download ZIP** на странице репозитория.

### 2. Положить скиллы к агенту

Скопируйте три папки в папку скиллов вашего агента:

| Агент | Куда класть |
|---|---|
| Claude Code | `~/.claude/skills/` |
| Codex | `~/.codex/skills/` |

Или попросите агента:

```
Скопируй папки docker-package, github-publish и timeweb-deploy
из этого репозитория в мою папку скиллов и покажи,
что они появились в списке доступных скиллов.
```

### 3. Положить свои ключи

Скопируйте `.env.example` в `.env` и впишите свои ключи:

```bash
cp .env.example .env
```

Где брать ключи — написано внутри `.env.example`, подробнее — в [WALKTHROUGH.md](WALKTHROUGH.md).

⚠️ **Файл `.env` никогда не попадает в интернет.** Он уже внесён
в `.gitignore`. Не присылайте его никому и не выкладывайте в репозиторий.

## Как пользоваться

Дальше вы просто разговариваете с агентом обычными словами.
Скиллы подключаются сами, когда задача им подходит.

```
Упакуй это приложение в Docker и запусти у меня на компьютере.
```

```
Создай приватный репозиторий на GitHub и закинь туда код.
```

```
Арендуй сервер, зарегистрируй домен мойсайт.ru
и опубликуй на нём это приложение.
```

Полный путь от папки с кодом до работающего сайта — в [WALKTHROUGH.md](WALKTHROUGH.md).

## Что нужно на компьютере

| Программа | Зачем | Проверить |
|---|---|---|
| **Docker Desktop** | собирает и запускает контейнеры | `docker --version` |
| **Git** | хранит историю изменений | `git --version` |
| **GitHub CLI** | создаёт репозитории | `gh --version` |

Чего нет — поставит агент. Попросите его:

```
Проверь, установлены ли Git, GitHub CLI и Docker.
Чего нет — установи. Потом авторизуй меня в GitHub
через gh auth login и покажи, под каким аккаунтом я вошёл.
```

## Безопасность

Три правила, которые скиллы соблюдают сами, но знать их надо:

1. **Ключи живут только в `.env`.** Никогда не в коде, не в переписке,
   не в репозитории.
2. **Ключ Timeweb даёт полный доступ к аккаунту** — включая удаление
   серверов. Обращайтесь с ним как с паролем от банка.
3. **Перед первым коммитом проверяется `.gitignore`.** Скилл
   `github-publish` делает это сам и не даст запушить `.env`.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Агент не видит скиллы | проверьте, что папки лежат в папке скиллов агента, перезапустите агента |
| `docker: command not found` | Docker Desktop не установлен или не запущен |
| `gh: not logged in` | выполните `gh auth login`, код вводится в браузере |
| Timeweb отвечает `no_paid` | не хватает денег на балансе, пополните |
| Домен не открывается | подождите: адрес расходится по интернету до нескольких часов |
