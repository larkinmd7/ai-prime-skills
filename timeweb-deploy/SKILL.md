# Публикация в интернете через Timeweb Cloud

Задача скилла: превратить упакованное в Docker приложение
в работающий сайт по своему домену.

## Главное правило

Пользователь — не системный администратор. Он говорит «выложи в интернет»
и ждёт ссылку. Все технические шаги делай сам, не переспрашивая
про операционную систему и конфигурации.

**Исключение — деньги.** См. следующий раздел.

---

## ⛔ Железное правило: деньги только с подтверждения

**Перед любой операцией, которая тратит деньги, покажи сумму
и дождись явного согласия.** Молча не покупать никогда.

Что требует подтверждения:

| Операция | Что показать |
|---|---|
| Аренда сервера | тариф, цена в месяц, регион |
| Регистрация домена | имя, цена за первый год, цена продления |
| Увеличение тарифа | старая и новая цена |
| **Удаление сервера** | что именно удаляется и что будет потеряно |

Формулировка: «Сервер 4 ГБ в России — 690 ₽/мес. Домен example.ru —
200 ₽ за первый год, продление 399 ₽. Итого сейчас спишется 890 ₽.
Подтверждаете?»

**Регистрация домена необратима.** Деньги не возвращаются,
имя закрепляется за владельцем на год.

⚠️ **Для доменов `.ru` и `.рф` данные владельца публичны** —
это правило реестра, скрыть их нельзя. Скажи об этом до покупки.

---

## Доступ

Ключ берётся из `.env`, переменная `TIMEWEB_CLOUD_TOKEN`.

```python
from dotenv import load_dotenv; load_dotenv()
token = os.getenv("TIMEWEB_CLOUD_TOKEN")
```

⚠️ **У ключа Timeweb нет ограничений прав.** Один ключ — полный доступ
ко всему аккаунту, включая удаление любых серверов. Никогда не печатай
его значение, не клади в код и не отправляй в переписку.

Получить ключ: `timeweb.cloud/my/api-keys` (в панели — вкладка
**«API и Terraform»**) → **«Добавить токен»** → имя любое, срок «Бессрочно»
→ **«Выпустить»**. Токен показывается **один раз**, начинается на `eyJ`.
Закрыли окно — только перевыпуск на той же странице.

## Первым делом — проверить баланс

**Пополнить баланс через API невозможно**, такого метода не существует.
Если денег не хватит, операция упадёт с `no_paid` посреди работы.

```bash
python3 scripts/twc.py balance
```

Нужно примерно: сервер от 500 ₽/мес + домен 200 ₽. Держи запас
хотя бы 1 500 ₽. Не хватает — скажи пользователю пополнить руками
в панели, не пытайся обойти.

## Порядок публикации

### 1. Проверить, готово ли приложение

У приложения должен быть `Dockerfile` или `compose.yml`.
Нет — сначала упакуй (скилл `docker-package`).

Код должен быть в GitHub-репозитории — сервер заберёт его оттуда.
Нет — сначала опубликуй (скилл `github-publish`).

### 2. Домен

```bash
python3 scripts/twc.py domain-check example.ru
```

Свободен → показать цену → **дождаться подтверждения** → зарегистрировать:

```bash
python3 scripts/twc.py domain-register example.ru
```

Занят — предложи варианты: другая зона (`.ru`, `.store`, `.site`),
другое имя.

### 3. Сервер

```bash
python3 scripts/twc.py presets          # посмотреть тарифы
python3 scripts/twc.py server-create --name myapp --ram 4096
```

**Как выбирать тариф:**

| Приложение | Память |
|---|---|
| Статика, лендинг, простой бот | 2 ГБ |
| Обычное приложение с базой | 4 ГБ |
| Обработка видео, распознавание речи, модели | 8 ГБ |

Сервер поднимается за полторы-две минуты. Дождись `status: on`.

**Ключ доступа создаётся сам.** Скрипт при первой аренде генерирует
SSH-ключ `~/.ssh/id_ed25519_timeweb`, загружает его в Timeweb и привязывает
к серверу. Без ключа на сервер не зайти, а деплою это нужно.

Вход: `ssh -i ~/.ssh/id_ed25519_timeweb root@<IP>` — скрипт печатает
эту строку после создания.

### 4. Направить домен на сервер

```bash
python3 scripts/twc.py dns-set example.ru <IP>
```

⚠️ **Домен заработает не сразу.** Адрес расходится по интернету
от получаса до нескольких часов. Предупреди пользователя честно,
не обещай «сейчас откроется».

Пока ждём — можно проверять по IP.

### 5. Развернуть приложение

По SSH на сервере:

1. Поставить Docker (`curl -fsSL https://get.docker.com | sh`).
2. Забрать код из GitHub.
3. Собрать образ и запустить контейнер.
4. Поднять Caddy как прокси — он сам выдаёт HTTPS-сертификат.

Минимальный `Caddyfile`:

```
example.ru {
    reverse_proxy app:3000
}
```

Больше ничего для HTTPS не нужно — сертификат выпускается
и продлевается автоматически.

### 6. Проверить

**Обязательно.** Не говори «готово», пока не увидел ответ:

```bash
curl -sS -o /dev/null -w '%{http_code}' https://example.ru
```

Должно быть `200`. Покажи пользователю ссылку и попроси открыть
**на телефоне** — так видно, что сайт доступен снаружи, а не только
с его компьютера.

## Два стенда: dev и prod

Когда у продукта появились пользователи, обновления идут через тест.

| Адрес | Ветка | Кто ходит |
|---|---|---|
| `example.ru` | `main` | пользователи |
| `dev.example.ru` | `dev` | владелец и тестировщики |

Оба стенда живут на одном сервере, это два контейнера
и два адреса в `Caddyfile`. Dev закрывается паролем:

```
dev.example.ru {
    basic_auth {
        admin <хеш>
    }
    reverse_proxy app-dev:3000
}
```

Хеш пароля: `docker run --rm caddy caddy hash-password --plaintext '<пароль>'`.

Поддомен создаётся так:

```bash
python3 scripts/twc.py subdomain-add example.ru dev
```

## Постоянные данные

Всё, что должно пережить обновление — база, загрузки, скачанные модели —
монтируется томом. Без тома данные сотрутся при первом же передеплое.

```yaml
volumes:
  - appdata:/app/data
```

## Удаление сервера

```bash
python3 scripts/twc.py server-delete <id>
```

⚠️ Требует подтверждения и **необратимо**. Перед удалением:

1. Назови, что именно удаляется, — имя и IP.
2. Предупреди, что данные на диске пропадут.
3. Дождись явного «да».

Если на аккаунте включено SMS-подтверждение удаления,
API вернёт `423` — код придёт пользователю на телефон.

**Скажи пользователю:** остановленный сервер продолжает
тарифицироваться. Не нужен — удаляй, а не выключай.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `no_paid`, `vds_blocked` | не хватает денег на балансе, пополнить руками в панели |
| Домен не открывается, сервер работает | DNS ещё расходится, ждать; проверить `dig example.ru` |
| `423` при удалении | включено SMS-подтверждение, код на телефоне владельца |
| Сборка падает на сервере | не хватает памяти; добавить swap или взять тариф больше |
| HTTPS не выпускается | домен ещё не указывает на сервер; Let's Encrypt проверяет владение |
| Контейнер падает после перезагрузки | нет `restart: unless-stopped` |
| Данные пропали после обновления | не подключён том |

---

## Чего не делать

- Не тратить деньги без подтверждения.
- Не удалять серверы, которые не создавал в этой задаче.
- Не печатать значение токена.
- Не обещать, что домен заработает мгновенно.
- Не говорить «готово», не проверив ответ сайта.
- Не класть секреты в репозиторий или в образ.
